# StudyLink React Frontend

This is the React Vite frontend application for StudyLink.

## Technology Stack
- React 18 / 19
- Vite 5 / 8
- Zustand (State management)
- Axios (HTTP requests)
- React Router 6 / 7 (Routing)
- Tailwind CSS 3 (Styling)

## Getting Started

### Prerequisites
- Node.js 18+

### Setup & Run
1. Navigate to the frontend directory:
   ```bash
   cd frontend
   ```
2. Install npm dependencies:
   ```bash
   npm install
   ```
3. Copy environment template:
   ```bash
   cp .env.example .env
   ```
4. Start the development server (with Hot Module Replacement):
   ```bash
   npm run dev
   ```
5. Build for production:
   ```bash
   npm run build
   ```
